## Conventions
- **Status values:** `planned` → `in-progress` → `shipped` (use `removed` for deleted features).
- Add a row when starting a new feature; update the status as it moves.
- Cross-link routes to their entries in `.claude/ARCHITECTURE.md`.
- When a feature is removed, keep the row but mark `removed` and note the removal date.
